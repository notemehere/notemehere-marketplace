# NoteMeHere marketplace

Plugins for [NoteMeHere](https://github.com/notemehere), a personal Notion replacement with an MCP server.

## Claude Code

```
/plugin marketplace add notemehere/notemehere-marketplace
/plugin install notemehere@notemehere
```

## Codex

```
codex plugin marketplace add notemehere/notemehere-marketplace
codex plugin add notemehere@notemehere
codex mcp login notemehere
```

## Plugins

- [notemehere](https://github.com/notemehere/notemehere-plugin) — the NoteMeHere MCP server and the `capture-note` / `find-notes` skills.
